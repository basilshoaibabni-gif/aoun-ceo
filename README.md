# Aaun — Portfolio

Portfolio website for **Aaun**, short-form video editor for real estate agents ([@aaun.ceo](https://www.instagram.com/aaun.ceo/)).

Plain HTML/CSS/JS. No build step, no dependencies.

## Run locally
Open `index.html` in a browser.

## Add reel videos
Put MP4 files in `videos/` named `reel1.mp4`, `reel2.mp4`, `reel3.mp4`, `reel4.mp4`.
Vertical 9:16, under ~10 MB each so the page loads fast. Until a file exists, its slot shows "Edit coming soon".

## Still to fill in
Search `PLACEHOLDER` in `index.html`:
- Facebook link
- WhatsApp / phone number
- Email
- Turnaround time and rate

Each Day clip in the series links to the Instagram profile. Swap in the direct reel links when available.

## Deploy (GitHub Pages)
Settings → Pages → Source: `main` branch, `/ (root)` → Save.
Site goes live at `https://<username>.github.io/<repo-name>/`.
